# Эталонная разметка DEV

Один файл на диалог: `<conversation_id>.json` с ответами по критериям стартового чек-листа.

**Статус:** черновик: разметка ИИ-ассистента по правилам PDF; нужно проверить человеку (особенно KZ).

`ambiguous` — критерии, где два разметчика могли бы ответить по-разному.

Соглашения:
- c07 «Завершение»: одного прощания мало, нужно прощание + (итог или предложение помощи); «Отлично. Хорошего дня!» = Нет.
- c07: если оператор закрыл чат без прощания — Нет; если связь оборвалась сразу после ответа — N/A.
- c02 «Выявление потребности»: N/A, если данных для ответа хватало с самого начала и оператор ответил сразу.
- c03: N/A, если не было ни раскрытия данных счёта, ни защищённого действия.
- ambiguous — критерии, где два разметчика могли бы ответить по-разному; точность считается и без них.
